# secoes-prontas

**Propósito:** Seções inteiras em HTML (timeline, FAQ, gráficos, tour 360).  
**Quando usar:** ao montar uma página e precisar desse tipo de efeito ou componente.  
**Relacionados:** [GUIA-CODIGOS.md](../GUIA-CODIGOS.md), [preview.html](../preview.html), [snippets.json](../snippets.json)

| Snippet | O que faz | Onde colar | Uso nas páginas da casa |
|---|---|---|---|
| [linha-do-tempo-etapas.html](linha-do-tempo-etapas.html) | Timeline vertical com eixo central e cards alternando esquerda/direita, que se revelam com o scroll. Ideal para "como funciona". | Widget HTML | 1 |
| [metodo-cartas-voando-scroll.html](metodo-cartas-voando-scroll.html) | Seção sticky de ~9 telas em que cartas com as etapas do método entram voando conforme a rolagem. | Widget HTML | 1 |
| [faq-duas-colunas.html](faq-duas-colunas.html) | Perguntas frequentes em duas colunas com abrir/fechar animado, sem depender do widget Acordeão. | Widget HTML | 1 |
| [grafico-valorizacao-barras.html](grafico-valorizacao-barras.html) | Gráfico de barras em HTML/CSS puro com títulos e fonte dos dados. Para lançamento imobiliário mostrar valorização da região. | Widget HTML | 1 |
| [grafico-faturamento.html](grafico-faturamento.html) | Gráfico escuro com barras/linha de faturamento e destaque laranja, para página de vendas mostrar resultado. | Widget HTML | 1 |
| [tour-360-momento360.html](tour-360-momento360.html) | Incorpora um tour 360 do Momento360 com cantos arredondados e altura responsiva. | Widget HTML | 1 |

Cada arquivo começa com um comentário padronizado: o que faz, como usar, onde colar, dependências, origem e em quais páginas da casa ele aparece.
