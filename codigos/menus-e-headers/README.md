# menus-e-headers

**Propósito:** Menus completos prontos para widget HTML.  
**Quando usar:** **só quando o usuário pedir menu.** Por regra fixa do PageBrain (24/10/2026), as páginas do PageBrain não têm menu e a logo fica na hero, acima da headline.
