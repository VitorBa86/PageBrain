# interacoes

**Propósito:** Pequenos scripts de interação (toggle, container clicável).  
**Quando usar:** ao montar uma página e precisar desse tipo de efeito ou componente.  
**Relacionados:** [GUIA-CODIGOS.md](../GUIA-CODIGOS.md), [preview.html](../preview.html), [snippets.json](../snippets.json)

| Snippet | O que faz | Onde colar | Uso nas páginas da casa |
|---|---|---|---|
| [toggle-abrir-fechar-container.html](toggle-abrir-fechar-container.html) | Função makeToggle: botões alternam a classe "ativo" num container (ex.: "ver mais" de um card). Estilize .ativo no CSS. | Widget HTML no fim da página | 1 |
| [container-clicavel-link.html](container-clicavel-link.html) | Faz qualquer elemento com a classe "link-site" abrir um link em nova aba. | Widget HTML | 1 |

Cada arquivo começa com um comentário padronizado: o que faz, como usar, onde colar, dependências, origem e em quais páginas da casa ele aparece.
