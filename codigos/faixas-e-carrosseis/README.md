# faixas-e-carrosseis

**Propósito:** Faixas infinitas (marquee), carrosseis contínuos e de avaliações.  
**Quando usar:** ao montar uma página e precisar desse tipo de efeito ou componente.  
**Relacionados:** [GUIA-CODIGOS.md](../GUIA-CODIGOS.md), [preview.html](../preview.html), [snippets.json](../snippets.json)

| Snippet | O que faz | Onde colar | Uso nas páginas da casa |
|---|---|---|---|
| [faixa-animada-infinita.html](faixa-animada-infinita.html) + [faixa-animada-infinita.elementor.json](faixa-animada-infinita.elementor.json) | Faixa horizontal que corre sem parar com frases separadas por ícone. Usada logo abaixo do hero ou entre seções. | CSS: CSS personalizado do widget Lista de Ícones. Script: widget HTML no fim da página. | 5 |
| [carrossel-linear-continuo.css](carrossel-linear-continuo.css) | Faz o Carrossel de Imagens do Elementor andar sem pausa e sem aceleração (efeito esteira). Configure autoplay com velocidade alta (ex.: 5000ms) e intervalo 0. | CSS personalizado do widget Carrossel de Imagens | 7 |
| [carrossel-imagem-largura.css](carrossel-imagem-largura.css) | Força a largura da imagem dentro de cada slide do Carrossel de Imagens. | CSS personalizado do widget Carrossel de Imagens | 8 |
| [carrossel-fade-lateral.css](carrossel-fade-lateral.css) | Escurece as bordas esquerda e direita do carrossel, dando efeito de que as imagens somem nas pontas. | CSS personalizado do widget Carrossel | 0 |
| [carrossel-mobile-autoscroll.html](carrossel-mobile-autoscroll.html) | No celular, transforma um container de imagens em faixa horizontal que rola sozinha (pausa ao tocar). No desktop não faz nada. | Widget HTML | 1 |
| [carrossel-avaliacoes-google.html](carrossel-avaliacoes-google.html) | Bloco com nota geral à esquerda e cards de avaliações rolando à direita, no visual do Google. | Widget HTML | 1 |

Cada arquivo começa com um comentário padronizado: o que faz, como usar, onde colar, dependências, origem e em quais páginas da casa ele aparece.
