# utilitarios-css

**Propósito:** CSS utilitário que se repete em quase toda página.  
**Quando usar:** ao montar uma página e precisar desse tipo de efeito ou componente.  
**Relacionados:** [GUIA-CODIGOS.md](../GUIA-CODIGOS.md), [preview.html](../preview.html), [snippets.json](../snippets.json)

| Snippet | O que faz | Onde colar | Uso nas páginas da casa |
|---|---|---|---|
| [css-base-toda-pagina.css](css-base-toda-pagina.css) | Seleção de texto discreta, sem rolagem horizontal, sem margem no último parágrafo e barra de rolagem personalizada. Vai em TODAS as páginas. | CSS personalizado da página | 33 |
| [scrollbar-colorida.css](scrollbar-colorida.css) | Variação da barra de rolagem com trilho e thumb coloridos. | CSS personalizado da página | 0 |
| [botao-icone-tamanho.css](botao-icone-tamanho.css) | Aumenta o ícone (ex.: WhatsApp) dentro do botão do Elementor e centraliza com o texto. | CSS personalizado do widget Botão | 12 |
| [faq-toggle-arredondado.css](faq-toggle-arredondado.css) | Arredonda o título de cada item do widget Alternar/Acordeão. | CSS personalizado do widget | 10 |
| [elemento-posicao-absoluta.css](elemento-posicao-absoluta.css) | Tira o widget do fluxo para sobrepor decorações, selos e imagens. É o CSS custom mais comum depois do CSS base (24 páginas). | CSS personalizado do widget | 27 |
| [menu-dropdown-mobile-centralizado.css](menu-dropdown-mobile-centralizado.css) | Faz o menu suspenso do widget Menu de Navegação ocupar 90% da tela e ficar centralizado. | CSS personalizado do widget Menu | 1 |

Cada arquivo começa com um comentário padronizado: o que faz, como usar, onde colar, dependências, origem e em quais páginas da casa ele aparece.
